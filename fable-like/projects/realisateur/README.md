# realisateur — the vision organ

"Scheduler runs things; realisateur perceives → judges → records." A steward
with sensory organs, not a second engine. Inbox at repo root; nightly run infers
dropped ideas into scaffolded, registered projects; owns cross-project triage,
milestones, and the `_paced.conf` weight field.

## What's different in the fable version

1. **Doctrine and journal are split.** Today `.claude/FOCUS.md` is 56 KB of
   standing decisions interleaved with dated log entries. Here: `DOCTRINE.md`
   holds the current-truth rules (identity seam test, vision-debt math, autonomy
   bar) and is *edited in place, superseded lines deleted*; `.scheduler/FOCUS.md`
   stays a lean dated journal. You already write "SUPERSEDED same day" — this
   just gives superseded text somewhere to die.
2. **A name registry exists** (`NAMES.md`, jointly owned with senechal, "keeper
   of names"). The live collision — two unrelated *bibliothecaire* ideas, one in
   crt's FOCUS, one at your inbox root — is exactly what a 20-line lookup table
   prevents. Nightly-batch checks it before every scaffold.
3. **The queued mechanical guards are built, because your own doctrine says
   guards beat reminders:** hygiene-lint's shared-host-footprint row; a
   milestone-format lint that says *"bar and status must share one line, fix
   like this"* instead of silently reporting UNRECOGNIZED. A guard with a known
   gotcha that bites three projects (gardien/senechal/wtul, 2026-07-24) is a
   reminder wearing a guard's clothes.

## Unchanged, because it's right

The inbox loop · park-by-default triage · offline surveys before AI reasoning ·
cross-write protocol (busy-check, small, committed immediately, dirty tree is a
stop) · /ideate's surface-ask-record posture · weight as realisateur's one
direct write into scheduler.
