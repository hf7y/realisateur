  milestone below stays on the utilities side of your own either/or until you
  decide otherwise by hand.
- The fork in your note (grant access vs. gives-me-utilities vs. managed
  thunderbird) is a genuine design fork — /ideate material, not nightly-batch
  material. Recorded here so the first batch run doesn't pick a lane silently.
