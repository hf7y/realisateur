# sequestria — carbon-capture seltzer

Seltzer brand concept using atmospherically-scrubbed carbon. Parked 2026-07-24;
brand direction flagged a forming dream. The hard fences are exemplary and the
fable version keeps every one: no supplier/certification claims, no
domain/trademark/company formation, no spending, no contacting the waitlist.
