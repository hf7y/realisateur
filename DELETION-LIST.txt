# in an agent's context. Any session -- or Zach -- can finish this by running
# the list. If the run dies at file 30 of 60, the next one reads this and
# continues. No plan state is held in a conversation.

#   git rm -q $(grep -v '^#' DELETION-LIST.txt | grep -v '^$')
#   bash bin/shellcheck-lint.sh --accept     # ratchet keys on (file,code) pairs
#
# WHY THESE: measured 2026-08-21. Six sampled guards = 1,029 lines, zero
# findings; four report clean, one exits 2 on a usage error, one times out.
# Guards are 5,673 of bin/'s 15,550 LOC. The estate's failure is not missing
# wiring -- it is wiring that runs, reports green, and cannot see. Ashby S.8/7:
# a transducer with fewer output values than its input has distinct states
# loses distinctions. That is the whole disease, and deletion is the only
# remedy that does not add another transducer.
#

# REQUIRED checks (enforce_admins=true -- breaking them makes the repo

# live ausculte probes. discipline.sh is CLAUDE.md's mandated front door.
# publish-monkey-status.sh + monkey-status-collect.py produce the dashboard
# Zach reads.
#
# silence-audit.sh and delivery-audit.sh ARE ausculte probes and are deleted
# anyway: silence-audit counts "named in a doc" as wired; delivery-audit reads
# `- none` on 260 of 262 PRs. Both are sensors that do not sense. ausculte
# drops from 8 probes to 6 in the same PR.
#

#   release-ledger.sh                             <- the verdict's consumer half
#   verb-kind-lint.sh                             <- cut-verb-build.sh, which
#       DIES without it: "Refusing to cut a build whose channel declarations
#       were never checked."
#   land-selfdev.sh, wire-selfdev-git.sh, wire-release-channel.sh
#                                                 <- setup-selfdev-project.sh,
#       the account-standup path
# The guard bucket below survived review nearly unchanged; the orphan bucket

# by the sprint that exists to remove it.
